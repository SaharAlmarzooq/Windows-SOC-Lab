## 📖 Overview

**Windows SOC Lab** is a hands-on cybersecurity project that documents the complete process of building a Windows-based Security Operations Center (SOC) lab from scratch.

The project focuses on understanding Windows endpoint telemetry, investigating security events using Sysmon, and developing practical SOC investigation skills through realistic analyst-driven scenarios.

Instead of simply learning security tools, this lab emphasizes understanding attacker behavior, collecting evidence, correlating multiple events, and making investigation decisions based on observed telemetry.

---

## 🎯 Objectives

- Build a professional Windows SOC Lab.
- Deploy and configure Microsoft Sysmon.
- Understand Windows Event Logging.
- Investigate endpoint telemetry.
- Correlate multiple Sysmon events.
- Perform Threat Hunting exercises.
- Conduct analyst-style incident investigations.
- Develop practical Blue Team skills.

## 💡 Key Takeaways

This project represents a structured learning journey toward becoming a Security Operations Center (SOC) Analyst.

Each session builds practical investigation skills by gradually progressing from Windows endpoint preparation and telemetry collection to threat hunting, event correlation, and analyst-driven incident response.

The primary objective is to strengthen analytical thinking and develop practical experience investigating Windows security events in a controlled lab environment.
