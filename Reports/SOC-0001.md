# Alert Summary

Microsoft Defender generated an alert indicating suspicious PowerShell file activity on the endpoint.

The objective of the investigation was to determine:

- What happened?
- Which file was involved?
- Which process performed the activity?
- Whether the activity required escalation.

---

# Investigation

The investigation began by reviewing **Sysmon logs**.

The analyst correlated:

- **Event ID 11** (File Create)
- **Event ID 1** (Process Create)

using the matching **ProcessGuid**.

Additional investigation included reviewing:

- **Event ID 3** (Network Connection)
- **Event ID 13** (Registry Value Set)

No related network connections or Registry modifications associated with the PowerShell process were identified.

# Analysis

The PowerShell process was launched by Windows Explorer under the logged-in user account.

The process created a PowerShell script named **QuarterlyReport.ps1** inside the **Reports** directory.

The investigation found no evidence of:

- Network communication
- Registry persistence
- Additional suspicious activity

The observed behavior was limited to local file creation.

---

# Final Verdict

| Field | Result |
|-------|--------|
| **Classification** | Benign Activity |
| **Escalation Required** | No |
| **Status** | Closed as Benign Activity |

### Reason

The alert was triggered because PowerShell created a script file.

The activity matched the expected behavior of the laboratory simulation.

No indicators of malicious activity were identified.

---

# Recommendations

- Close the alert as **Benign Activity**.
- Continue monitoring future PowerShell activity.
- Investigate future PowerShell executions that include:
  - Network connections
  - Encoded commands
  - Registry persistence
  - Suspicious child processes
