# Alert Summary

The monitoring system generated an alert after detecting PowerShell activity on the endpoint.

The objective of this investigation was to determine whether the PowerShell process performed suspicious actions such as creating malicious files, establishing unauthorized network connections, or modifying the Windows Registry for persistence.

---

# Investigation

## Step 1 — Process Creation (Event ID 1)

The investigation started by reviewing **Event ID 1** to identify the PowerShell process responsible for the alert.

### Evidence

| Artifact | Value |
|----------|-------|
| **Image** | `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe` |
| **User** | `SOC-WIN11-01\SOCAdmin` |

The event confirmed that PowerShell was executed successfully by the logged-on user.

---

## Step 2 — File Creation (Event ID 11)

Event ID 11 was reviewed to determine whether PowerShell created any files during execution.

### Evidence

| Artifact | Value |
|----------|-------|
| **Target Filename** | `C:\Users\SOCAdmin\Desktop\Reports\Investigation.ps1` |

The investigation confirmed that PowerShell created a PowerShell script named **Investigation.ps1**.

---

## Step 3 — Network Connection (Event ID 3)

Event ID 3 was reviewed to identify outbound network communication generated by the PowerShell process.

### Evidence

| Artifact | Value |
|----------|-------|
| **Image** | `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe` |
| **Destination IP** | `104.20.23.154` |
| **Destination Port** | `443` |

### IP Reputation

| Artifact | Value |
|----------|-------|
| **Source** | VirusTotal |
| **Result** | Clean (0 detections) |

The destination IP address was not identified as malicious.

---

## Step 4 — Registry Investigation (Event ID 13)

Event ID 13 was reviewed to identify any Registry modifications associated with the investigated PowerShell process.

### Result

No Registry modifications were identified.

No evidence of persistence mechanisms was found.

---

# Event Correlation

The following Sysmon events shared the same **ProcessGuid**, confirming that they originated from the same PowerShell process:

# Analyst Assessment

| Field | Result |
|-------|--------|
| **Risk Level** | Low |

The investigation confirmed that PowerShell executed successfully, created a PowerShell script, and established an outbound HTTPS connection.

No additional indicators of compromise (IOCs) were identified during the investigation.

| Field | Result |
|-------|--------|

Based on the collected evidence, the observed behavior represents legitimate PowerShell activity.

The PowerShell process created a local script and established an outbound HTTPS connection to a trusted destination without exhibiting persistence or other malicious behavior.
